# Lakshmanan Kandhan Portfolio 🚀

A modern and responsive personal portfolio website built using **React + Vite + Tailwind CSS**.
This portfolio showcases my projects, video editing works, freelance services, and contact details.

---

## 🌟 Features

* ✨ Modern animated UI using Framer Motion
* 🎞️ Video Editing Showcase Section
* 🖼️ Hero Image Slider using Swiper.js
* 💼 Project Showcase with Live Website Links
* 📱 Fully Responsive Design
* 💬 WhatsApp Direct Contact Integration
* 📧 Contact Form using EmailJS
* 🔗 Social Media Links
* 🚀 Fast Performance with Vite

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/LAKSHMANANKANDHAN/your-repo-name.git
```

Go to project folder:

```bash
cd your-repo-name
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 📧 EmailJS Setup

1. Create account in EmailJS
2. Create Service
3. Create Template
4. Replace these values in `App.jsx`

```js
service_id
template_id
public_key
```
